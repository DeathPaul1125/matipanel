Consultando el servidor de correo…

Postfix no está instalado

Postfix es el servidor SMTP: recibe correo de internet para tus dominios, entrega el correo a los buzones locales y envía los mensajes que salen del servidor (avisos del sistema, formularios de tus sitios, etc.). Se instala como Sitio de Internet usando como nombre de correo el nombre completo del servidor.

apt install postfix

Dovecot no está instalado

Dovecot es el servidor IMAP y POP3: permite que los usuarios lean su correo desde Thunderbird, Outlook o el celular. Solo lo necesitas si este servidor guarda buzones de usuarios; para un servidor que solo envía avisos basta con Postfix.

apt install dovecot-imapd dovecot-pop3d
