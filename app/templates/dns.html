Ten tu propio servidor DNS con BIND 9

BIND (named) es el servidor DNS más usado en Linux. Con él este servidor puede publicar tus dominios (zonas primarias con registros A, MX, TXT…), actuar como secundario de otro servidor o servir de resolvedor/caché para tu red interna. Al instalarlo queda activo como resolvedor para el propio servidor y la red local; no publica ningún dominio hasta que crees una zona.

La instalación automática solo está disponible en Debian/Ubuntu. En Debian se instalaría con:

apt install {{ packages }}
