Consultando Samba…

Comparte carpetas con Samba

Samba convierte este servidor en un servidor de archivos compatible con Windows: los equipos de la red abren las carpetas compartidas desde el Explorador de archivos (\\servidor\recurso) y también funcionan macOS y Linux. Cada persona entra con un usuario y contraseña de Samba, y puedes decidir quién lee y quién escribe en cada carpeta.

{% if apt %} {% else %}

La instalación automática solo está disponible en Debian/Ubuntu. Instálalo desde la terminal:

apt install samba smbclient
{% endif %}

Samba usa su propia contraseña, distinta de la de Linux, pero cada cuenta debe corresponder a un usuario de Linux existente (créalo en Usuarios y grupos). Los permisos de Linux de la carpeta siguen aplicándose: el usuario necesita permiso de escritura en la carpeta además de en el recurso.

Cómo conectarse

Pulsa «Conectar» en un recurso para ver sus comandos
Windows
\\{{ server }}\recurso
macOS
smb://{{ server }}/recurso
Linux (escritorio)
smb://{{ server }}/recurso
Linux (terminal)
mount -t cifs //{{ server }}/recurso /mnt/recurso -o username=USUARIO

Firewall: Samba usa los puertos 445/TCP y 139/TCP (y 137-138/UDP para la búsqueda de equipos). Ábrelos solo para tu red interna en Firewall.

Consultando NFS…

Comparte carpetas con NFS

NFS (Network File System) es la forma nativa de compartir carpetas entre servidores Linux: el otro equipo «monta» la carpeta y la usa como si fuera un disco local. Es ideal para compartir datos entre servidores, respaldos o clústeres. El acceso se controla por dirección IP o red del cliente.

{% if apt %} {% else %}

La instalación automática solo está disponible en Debian/Ubuntu. Instálalo desde la terminal:

apt install nfs-kernel-server
{% endif %}
