Aplicaciones

Publica tus aplicaciones Laravel desde GitHub

Conecta un repositorio y el panel se encarga del resto: descarga el código, construye una imagen Docker (PHP + Nginx, Composer y los assets con npm), ejecuta las migraciones y la publica en un puerto propio o con un nombre interno como miapp.apps.empresa.local. Cada nuevo commit se despliega solo y sin cortes: la versión nueva arranca al lado de la actual y Nginx cambia cuando ya responde. Si algo falla, la versión anterior sigue en línea y puedes revertir con un clic.

Agrega esta clave de despliegue en GitHub: en el repositorio, Settings → Deploy keys → Add deploy key. Ponle un título (por ejemplo MatiPanel), pega la clave y no marques Allow write access.

Repositorio público por HTTPS: no hace falta clave. Prueba el acceso para confirmar que el panel lo puede leer.

Si la app usa una base que ya existe, completa sus datos y se escriben en el .env. Déjalo vacío si no usa base de datos o la configurarás después.
Para una base instalada en este mismo servidor usa host.docker.internal: dentro del contenedor, localhost es el propio contenedor. La base debe aceptar conexiones desde la red de Docker (bind-address y permisos del usuario desde 172.%).
