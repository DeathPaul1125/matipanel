PHP no está instalado

Instala PHP-FPM y CLI (versión por defecto de Debian):

apt install php-fpm php-cli

Para tener varias versiones en paralelo (p.ej. 8.1, 8.3, 8.4) agrega el repositorio de Ondřej Surý:

apt install -y lsb-release ca-certificates curl
curl -sSLo /usr/share/keyrings/deb.sury.org-php.gpg https://packages.sury.org/php/apt.gpg
echo "deb [signed-by=/usr/share/keyrings/deb.sury.org-php.gpg] https://packages.sury.org/php/ $(lsb_release -sc) main" > /etc/apt/sources.list.d/php.list
apt update && apt install php8.3-fpm php8.3-cli
